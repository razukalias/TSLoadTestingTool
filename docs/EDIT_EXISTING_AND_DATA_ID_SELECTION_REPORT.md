# Existing Instance Editing and Unified Run Selection

Date: 2026-10-05

## Delivered

The Config tab exposes **Edit DataEngine workbook** for an existing instance. The editor now uses a compact guided grid instead of a long row of controls. Workbook sheets are available as tabs: `config`, `request`, `response`, and `README`.

The grid supports horizontal scrolling, frozen header semantics, column filtering by header, add row, delete row, add column, direct cell editing, and a raw workbook fallback. The selected cell is shown in the right-side **Cell wizard**.

The wizard provides context-sensitive help and compatible token insertion. It includes common functions such as `<randomnumber>`, `<randomnumber(1,100)>`, `<From_variable>`, `<uuid()>`, `<now()>`, and `<jsonpath>`. Response cells expose assertion verbs including `eq`, `contains`, `regex`, `exists`, `notexists`, `empty`, `notempty`, `gt`, `gte`, `lt`, `lte`, `in`, and `size`. Assertion cells are written in the existing runner syntax, for example `{eq}200` or `{contains}completed`.

The run chooser contains four coordinated panels: **Testcases**, **Test steps**, **Environments**, and **Data IDs**. Data IDs are grouped by testcase and persisted together with testcase, step, and environment selections. An empty data-ID selection means all request rows.

Saving an edited workbook creates a timestamped `.backup.*.xlsx` copy before writing. The original workbook contract remains unchanged, and the raw workbook can still be opened through the system-default application.

## Validation

The complete solution builds with zero errors. The existing selection regression suite passes all 38 checks. The Windows self-contained package is generated by the packaging script and ZIP integrity is verified.
