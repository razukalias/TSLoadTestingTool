# Existing Instance Editing and Unified Run Selection

Date: 2026-10-05

## Delivered

The Config tab now exposes **Edit DataEngine workbook** for an existing instance. It opens the workbook inside the UI and provides editable sheets for `config`, `request`, `response`, and `README`. Cells can be changed directly, rows can be added or deleted, and saving creates a timestamped `.backup.*.xlsx` copy before writing the workbook. The original workbook contract remains unchanged.

The run chooser now contains four coordinated panels: **Testcases**, **Test steps**, **Environments**, and **Data IDs**. Data IDs are grouped by testcase and are persisted together with the testcase, step, and environment selection in `.run-selection.json`. An empty data-ID selection means all request rows, preserving the previous behavior. The old separate Configure data IDs workflow was removed from the Config panel.

## Validation

The complete solution builds with zero errors. The existing selection regression suite passes all 38 checks. The Windows self-contained package is generated by the existing packaging script and includes the updated UI and runner.

## Notes

The workbook editor is intentionally a compatible sheet editor rather than a second workbook format. It is useful for correcting existing configuration, request rows, response assertions, and documentation immediately. The next refinement can add type-specific forms and stronger cell-level validation for HTTP, GraphQL, SQL, File, and Script rows.
